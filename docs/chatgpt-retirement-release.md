# Customer ChatGPT retirement

Customer project work stays in the standalone StreamLion workspace. Remove the prepared own-ChatGPT copy/open flow, brief prompts and return instructions, and both distributable plugin packages. Ask keeps free saved-detail lookup, its gated credit-backed assistant and ordinary project-snapshot download. Project creation keeps manual entry and neutral saved-project JSON import with review before saving. Device backups and Google-owned records are unchanged.

Both MCP endpoints, extension OAuth authorization/token/revocation routes and OAuth discovery return HTTP 410 with no-store headers, before authentication, database access, body parsing or tools. Middleware also denies descendants and the former public `/extension.html` fixture. Legacy clients cannot restore access by using a retained token or the old pilot flag. The production Pages extension flag is false. Generated historical extension UI remains a local test fixture under `server/generated/`, outside the public build. Historical internal modules and tests remain for existing cleanup and security coverage; they have no public entrypoint. The plugin packages are removed from source, not repackaged for distribution.

No migration, table deletion, record rewrite, secret rotation, new provider configuration or paid call is required. Keep the cleanup Worker's existing extension flag and schedule: old grants/tokens and temporary review copies must continue expiring. Do not disable cleanup or delete retained records as part of retirement. Google disconnect revocation is unchanged.
